# 0.2.1 验证记录

日期：2026-10-19。这是本地检查记录，不代表所有系统和未来版本均已验证。

## 已完成

- Windows 本机使用 Node.js 26.4.0、Playwright 1.64.0 和已安装 Edge：13 项测试全部通过、无跳过。覆盖宿主品牌下方挂载、独立模拟网站中的原生 LOGO 下方按钮、重复注入、网页侧栏重建/折叠、来源与信号检查、480px 视口、深色背景变量、草稿和网页保留、焦点隔离、卸载、异步晚返回、租约释放、加载/崩溃恢复及 URL 处理。
- 原始 Windows Desktop 0.2.0-rc.2 和 0.2.1-rc.2 归档：在临时副本中验证安装、重复安装、完整备份、拒绝覆盖变更文件、损坏备份/清单/操作锁拒绝，以及字节完全一致的回退。原始程序不作为公开测试附件。
- 真实 Electron 的两个独立进程、独立临时用户目录和回环 HTTP 服务：合成的持久 Cookie、localStorage、IndexedDB 重启后均保留。精确插件工作区使用持久分区，其他工作区使用不同临时分区；其他窗口不能释放本窗口的租约。
- 真实 Desktop 0.2.1-rc.2：通过桌面自带 CLI 安装插件 0.2.1；确认重复页头已移除、切换按钮位于网站自己的蓝色 LOGO 下方且不遮挡新对话入口、双向切换和网页侧栏折叠备用入口。正常退出并重启后，网站保持已登录状态。未自动执行登录或发送聊天。
- 发布允许清单检查：普通插件包和源码包排除桌面程序、个人配置、登录资料、本地备份及依赖目录；检查常见凭据格式和个人路径。另行查看实际归档清单。
- 公开发布前复核全部 27 个源码文件：未发现真实凭据、私人邮箱、个人用户路径或会话资料。凭据 URL 命中仅为测试中的 `example.org` 合成用例。使用 npm 官方 registry 执行依赖审计，报告 0 个已知漏洞；这不代表不存在尚未披露的漏洞。
- CI 保持只读权限，第三方 Actions 固定到核实过的提交，checkout 不保留仓库访问凭据。公开提交使用 GitHub 隐私邮箱。

## 已修正的问题

移除 DeepSeek 模式额外页头，在网站自己的 LOGO 下增加单入口，让新对话按钮自然下移。正常加载时隐藏恢复工具；网页侧栏收起或无法定位品牌时显示右上角备用入口。仅在网站精确来源内安装布局适配，重复加载不重复创建按钮。

沿用已有修正：隐藏 Harness 时暂时禁用其焦点，返回或卸载时恢复；网页失败与崩溃允许重新建立租约；卸载时处理晚返回的租约和失败的清理回调。

可选登录工具改为显式选择归档、精确主代码校验、运行状态检查、排他锁、先备份/记录恢复清单、原子替换和严格回退。旧原型的备份格式不冒充新版已验证备份。

## 仍有限制

- GitHub Actions 配置 Windows/Linux、Node.js 22，每次推送运行；实际结果见[仓库 Actions](https://github.com/abalika/dsh-mode-switch/actions)。上述本机结果不能当作该 CI 或所有 Node 版本的结果。公开 CI 不附带桌面归档，因此相应集成用例会明确跳过。
- 真实桌面人工检查使用 Windows、浅色主题和常规窗口。480px/深色变量来自模拟宿主测试；其他操作系统、真实深色/全屏/触摸布局尚需人工验证。
- 宿主品牌下方没有正式公开插槽，网站布局也可能更新，两处适配均可能需要随之调整。无法定位网站品牌时保留备用返回入口。0.2.0-rc.2 的补丁已验证，完整 UI 人工验收使用 0.2.1-rc.2。
- 登录保存是额外、明确选择的 Windows 程序补丁，不是普通插件 API；不保证网站永远不要求重新登录。原型安装可能缺少新版格式备份，见安装指南。
- 下载、设备权限、部分网站弹窗继续受宿主策略限制。插件不绕过网站或宿主限制。
- 自动扫描不是完整的秘密检测或外部安全审计；发布前仍需审阅文件内容。个人桌面截图和测试资料不随包分发。

旧 0.1.1 和上一版 0.2.0 已单独冻结为本地 UI 回退包，不进入公开源码包。更换 UI 包不需要恢复登录分区补丁。持久存储的独立 Electron 验证来自上一版；本次未修改该实现，并重新通过全部归档测试及真实桌面重启检查。
